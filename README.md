# &#x20;Onde as estrelas guardam você

Existem coisas que a gente simplesmente não consegue expressar em uma conversa. Às vezes, as palavras aparecem tarde demais; outras vezes, são tantas que não sabemos por onde começar.

Foi pensando nisso que decidi criar este pequeno universo.

**Onde as estrelas guardam você** é um projeto pessoal, desenvolvido com HTML, CSS e JavaScript. Mas, acima de tudo, é uma maneira diferente que encontrei de transformar sentimentos em algo que pudesse ser visto, explorado e, quem sabe, guardado na memória de alguém.

A ideia nunca foi construir algo grandioso ou tecnicamente extraordinário. Eu só queria criar um lugar especial, onde cada detalhe tivesse algum significado.

## &#x20;Um pouco sobre o projeto

Tudo começa com um céu estrelado.

Entre as estrelas existe uma constelação inspirada em Escorpião, formada por 18 pontos interativos. Cada um guarda uma mensagem, uma poesia ou um pensamento que, por algum motivo, eu queria compartilhar.

Mas as estrelas são apenas o começo.

Conforme a pessoa percorre esse pequeno céu, outras partes da experiência vão sendo reveladas: três cartas escritas para momentos diferentes, uma história sobre sentimentos que nem sempre parecem possíveis fora dos livros e algumas palavras que preferi deixar guardadas para o final.

Não existe pressa para chegar ao fim.

A intenção é que cada descoberta tenha seu próprio momento.

## &#x20;Como foi feito

O projeto foi desenvolvido utilizando:

- **HTML5**, para organizar toda a experiência.
- **CSS3**, responsável pelo céu noturno, pelas animações e pela identidade visual.
- **JavaScript**, que dá vida às estrelas, às mensagens e à progressão da jornada.

Procurei manter tudo relativamente simples, sem depender de grandes bibliotecas ou ferramentas desnecessárias.

Boa parte dos detalhes visuais foi construída diretamente com CSS, enquanto o JavaScript cuida das interações e das pequenas transições entre os diferentes momentos.

O projeto também foi pensado para funcionar tanto no computador quanto no celular.

## &#x20;Por que estrelas?

Talvez porque sempre tenha existido algo bonito na ideia de olhar para o céu e imaginar quantas histórias poderiam estar escondidas ali.

Ou talvez porque as estrelas tenham essa maneira curiosa de continuar brilhando, mesmo quando ninguém está olhando.

Não sei exatamente.

Mas gosto de pensar que algumas pessoas também são assim.

E que, às vezes, tudo o que precisam é de alguém disposto a enxergá-las.

## &#x20;Sobre este repositório

Este é um projeto pessoal, feito com carinho e desenvolvido aos poucos.

Algumas partes surgiram de ideias planejadas; outras apareceram durante a construção, quando percebi que poderia acrescentar mais um detalhe, melhorar uma animação ou encontrar uma maneira mais bonita de apresentar determinada mensagem.

Talvez o código não seja perfeito. Ainda estou aprendendo, experimentando e descobrindo novas maneiras de transformar aquilo que imagino em algo real.

Mas cada parte deste projeto tem uma razão para estar aqui.

E, sinceramente, isso é o que mais importa para mim.
